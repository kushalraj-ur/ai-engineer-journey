Python: Python is a high-level, object oriented ,dynamically typed, interpreted scripting language, as well as programming language.

High-level language : it's a human readable language
Object oriented language : it supports classes and objects
Dynamically typed language : the type of variable decided during runtime
Interpreted scripting language : line by line interpretation take place. The code will be executed until the interpreter reaches the line with error.
Programming language : will be compiled. If there is a one line error, the rest of the code will not executed.

Runtime: the time taken by the machine to execute the program.
Compile time: the time taken by the compiler to compile the program

8. Type casting / type conversion:
*Type casting is the process of converting one data type into another data type.
*There are 2 types of casting:
i. Implicit type casting: it's a process where Python interpreter convert one data type into another data type .automatically
*example : 
a = 10
b = 2.5
c = a+b
print(c,type(c)) //12.5 <class,'float'>

ii. Explicit tape casting: it's a process where user forcefully convert on data type into another data type.
*syntax:
var_name = data_type(input(msg))
*example:
a = int(input('enter number:))

10. Operators
*Operators : they are the symbols that perform specific operations.
*Operands : they are the values on which operation take place.

* three types of operators:
i. Based on number of operators - unary operator(NOT) , binary operator (AND / OR),ternary operator.

ii. Based on operation - arithmetic operation, Relational operation, logical operation, bitwise operation, assignment operation(short hand assignment operation).
a. Arithmetic operation : used to perform an arithmetic operations such as addition(+), subtraction(-), multiplication(*), division(/), modulus(%), exponential(**).
b. Relational operation : use it to compare the two values using ==,!=,<,>,<=,>=.
c. Logical operation : compare the multiple condition and returns boolean values(true and false) such as AND,OR,NOT.
d. Bitwise operation : bitwise AND, bitwise OR ,XOR,>>(right shift),<<(left shift), bitwise NOT/tilde.
e. Assignment operation : assign a value to variable using =.
f. Shorthand assignment operation : combination of arithmetic operator and assignment operator such as +=,-=,/=,\=.

iii. Special operators - membership operator, identity operator, dot operator, decorating, slicing.
a. Membership operator : used to check whether the element is member of the collection or not using(in, not in)
b. Special operators : used to compare the ID of two variables using (is ,is not)

13. Function: a block of code written for reusability and modularity and it executes when it's called.
* types of function:
1. Built-in function - pre-defined functions in python like ,push, pop, append ,copy,etc
2. User defined function(UDF) - the function which is defined by the user is called as user different function.
*syntax : def function_name :// function definition
          //statements
          function_name() // function calling 
*type of UDF:
i.No Arguments, No Return Value. The function performs a fixed task and prints or updates something directly without sending data back.
  example:
  def greet():
      print("Hello, World!")

  greet()
ii.With Arguments, No Return Value. The function accepts input data to process, but it does not return a result to the caller.
  example:
  def greet_user(name):
      print(f"Hello, {name}!")

  greet_user("Alice")
iii.No Arguments, With Return Value. The function takes no inputs, generates or fetches a value internally, and sends it back using return.
  example:
  def get_pi():
      return 3.14159

  pi_val = get_pi()
iv.With Arguments, With Return Value. The function takes input values, processes them, and returns the final result.
  example:
  def add(a, b):
      return a + b

  total = add(5, 3)
